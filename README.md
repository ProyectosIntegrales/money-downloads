# Money – Finanzas del hogar · descargas

Instaladores de **Money** para Windows, de [Proyectos Integrales](https://proyectosintegrales.mx/money/).

- **Última versión para Windows:** [Money-windows-x64.msi](https://github.com/ProyectosIntegrales/money-downloads/releases/latest/download/Money-windows-x64.msi)
- **Android:** desde Google Play.
- **Qué cambió en cada versión:** [Novedades](https://proyectosintegrales.mx/money/novedades/)

Si Windows muestra «Windows protegió tu PC», elige *Más información › Ejecutar de todas formas*. Si ya tienes Money, el instalador lo actualiza y conserva tus datos.

Este repositorio solo guarda los instaladores; el código de la app no está aquí.
